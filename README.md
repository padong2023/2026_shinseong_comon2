# 📸 신성 인생네컷 - Canon SELPHY CP1500 인쇄 설정 가이드

## 🖨️ 무여백(흰 테두리 없는 4x6 꽉 찬 인쇄) 설정법

### 1. 윈도우 프린터 기본 설정 (최초 1회 설정)
1. 윈도우 **[설정]** → **[Bluetooth 및 장치]** → **[프린터 및 스캐너]** 이동
2. **"Canon SELPHY CP1500"** 클릭 후 **[인쇄 기본 설정]** 클릭
3. **[고급]** 탭 선택:
   - **용지 크기**: `엽서` (또는 `Postcard` / `4 x 6 인치`)
   - **프린트 기능** 항목:
     - **여백 없이 인쇄**: `켬` (Borderless)
     - **크기 조정**: `없음` (100%)

---

### 2. 브라우저(크롬 / 엣지) 인쇄 대화상자 설정 (중요 ⚠️)
웹에서 인쇄창이 떴을 때 오른쪽 설정 메뉴를 확인하세요:
- **대상**: `Canon SELPHY CP1500`
- **용지 크기**: `엽서` (또는 `Postcard` / `4 x 6 인치`)
- **여백**: **`없음` (None)** 👈 *기본값으로 두면 브라우저 자체 여백이 생기므로 반드시 '없음'으로 선택!*
- **배율**: **`100%`** (또는 `맞춤`)
- **옵션**: **`배경 그래픽`** 체크
