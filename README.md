1. 윈도우 **[설정]** → **[Bluetooth 및 장치]** → **[프린터 및 스캐너]** 이동
2. **"Canon SELPHY CP1500"** 클릭 후 **[인쇄 기본 설정]** 클릭
3. **[고급]** 탭 선택:
   - **용지 크기**: `Japan Postcard` (100 x 148 mm)
   - **프린트 기능** 항목:
     - **여백 없이 인쇄**: `켬` (Borderless)
